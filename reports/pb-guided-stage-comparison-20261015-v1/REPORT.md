# 동일 100개 pocket의 단계별 PoseBusters 결과

PB-Valid는 고정 6 Å protein-only pocket에서 PoseBusters dock의 20개 검사를 모두 통과한 비율이다. 분자별 연속 점수나 결합력 점수가 아니다.

원본 ligand는 pocket 위치·원자 수를 제공한다. 첫 생성은 원본 graph/좌표를 고정하지 않는 de novo 생성이다. 재생성은 첫 생성물의 graph/입체화학을 유지하고 PB 위반으로 정한 영역의 좌표만 바꾸는 pose-only 방식이다.

| 단계 | PB 통과 / 전체 예정 | PB-Valid |
| --- | ---: | ---: |
| 원본 native ligand | 89/100 | 89.00% |
| 첫 생성물 (pocket당 16개) | 1459/1600 | 91.19% |
| targeted: 실패 입력별 선택된 재생성물 | 9/41 | 21.95% |
| random: 실패 입력별 선택된 재생성물 | 8/41 | 19.51% |
| whole: 실패 입력별 선택된 재생성물 | 15/41 | 36.59% |
| UFF_targeted: 실패 입력별 선택된 재생성물 | 9/41 | 21.95% |

첫 생성 결과 중 PB 통과/실패 판정 가능한 결과는 1538개이며 그중 1459개 통과: 94.86%. 생성 실패 54개, PB 측정 시간 초과 8개는 전체 예정 1,600개 분모에 남긴다. 이 62개를 측정된 PB 실패로 해석하지 않는다. 별도로 1개는 InChI 검사 실패와 내부 에너지 검사 누락이 함께 있어 전체 PB 실패가 확정된 부분 측정 결과다.

PB가 실패한 79개 중 위치를 지정하여 부분 pose 복구를 시도할 수 있는 41개가 재생성 대상이다. 이들의 수정 전 PB 통과는 0/41이다. 나머지 38개 실패는 이번 부분 복구에서 제외됐다.

각 FM 방법은 실패 입력당 8개 후보를 생성하고 PB 통과·보존 조건을 우선해 하나를 선택했다. UFF는 입력당 한 번 수행한 CPU 대조군이다.

| 방법 | 모든 재생성 후보의 PB 통과 | 입력별 선택 성공 | 기존 통과 생성물을 유지한 최종 전체 통과 | 증가 |
| --- | ---: | ---: | ---: | ---: |
| targeted | 52/328 (15.85%) | 9/41 (21.95%) | 1468/1600 (91.75%) | +0.5625 pp |
| random | 44/328 (13.41%) | 8/41 (19.51%) | 1467/1600 (91.69%) | +0.5000 pp |
| whole | 72/328 (21.95%) | 15/41 (36.59%) | 1474/1600 (92.12%) | +0.9375 pp |
| UFF_targeted | 9/41 (21.95%) | 9/41 (21.95%) | 1468/1600 (91.75%) | +0.5625 pp |

원본 100개·첫 생성물 1,600개·실패 부분집합 41개는 분모가 다르므로 단계별 비율을 직접 빼서 동일 분자의 개선량으로 해석하면 안 된다. 동일 생성 결과에 대한 전체 비교는 첫 생성물과 최종 전체 1,600개 결과다.

원본 PB 기록 출처: {'existing_same_native_and_pocket': 88, 'additional_cpu_measurement': 12}. 원본 SDF와 pocket 경로를 확인해 기존 기록을 재사용했고 없는 항목은 동일 PB 설정으로 CPU 측정했다. 출처·SDF/pocket 해시는 native_measurements/에 저장했다.

PB가 진단 기준이자 후보 선택 기준이므로 PB 자체의 개선이다. 결합력·활성 개선이나 독립 평가에서의 일반화를 뜻하지 않는다. 물·보조인자를 포함한 전체 단백질 PB와도 구분해야 한다.

- per_ligand_pb.csv: 원본, 첫 생성물, 모든 재생성 후보의 PB와 개별 검사 실패 및 SDF 경로.
- repair_before_after.csv: 동일 41개 입력의 방법별 수정 전/선택 후 결과.
- per_complex_pb.csv: pocket별 세 단계 통과 수.
- summary.json: 전체 집계와 분모·실측 여부.
